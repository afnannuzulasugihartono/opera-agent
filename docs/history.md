# Project History

## Early experiments

The project started as experiments for controlling the user's local Opera browser from ChatGPT.

The work covered:

- tab control
- page-state reading
- click, fill, key, and scroll interactions
- YouTube automation
- crawling and research
- Supabase relay experiments

## Local Opera Agent v3

The v3 series proved the main concept:

- local Opera control
- Supabase command queue
- trusted input using debugger/CDP
- YouTube recommendation playback
- ad skipping
- semantic page reading
- multi-page crawling
- cross-chat access

## Opera Agent rebuild

The project is being rebuilt under the shorter name **Opera Agent**.

The new version line starts at **1.0.0**.

Legacy builds remain documented for reference but are not part of the new version sequence.
