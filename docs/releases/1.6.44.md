# WHAT REACHED THE BROWSER

**The extension can capture a page over time now** - not one still, one
sequence. `record_start` arms a recording on the tab; every command that
runs against it from then on - clicks, fills, scrolls, whatever the task
needs - lands in a single webm in the user's Downloads folder, and
`record_stop` finalizes it with the byte count, the duration, and up to
four sampled stills of the frames that mattered. The same refusal applies
as everywhere else: a page with a visible password, OTP or payment field
is never recorded.

**The extension can carry a page offline.** `scan_page` writes one
self-contained HTML file to Downloads: the rendered light DOM, its
stylesheets, its scripts (integrity kept), its images, icons, srcset and
every @font-face font the stylesheets reference, inlined as data URLs -
shadow roots are not serialized. The file works from `file://` with no
server, no network and no stylesheet of yours missing. It refuses a page
with a visible password, OTP or payment field the same way.
