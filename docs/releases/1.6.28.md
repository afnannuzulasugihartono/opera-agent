# @title: 1.6.28 — the whole page in one answer, and a worker that says what broke.
# @state: the release note for the version now shipping.
# @dependencies: none.

The page map reads a whole document in one call now, every element carrying the
class it belongs to, so a model no longer walks seventeen classes by hand. The
worker catches its own faults, and the status says whether the extension is
installed at all, so "never installed" is no longer read as "asleep".

The version moves because Chrome only installs an update when the version
rises: a CRX published under the version already installed never reaches
anyone, and that is how a build with the whole-page map stayed on the machines
that needed it.
