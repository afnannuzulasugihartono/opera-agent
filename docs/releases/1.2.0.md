# Opera Agent 1.2.0

Status: prepared same-identity release candidate; production deployment and signed artifact publication remain pending.

## Added

- `browser.burst` for 1-8 sequential page actions on one tab through one durable relay command.
- Supported actions: read, find, click, fill, key, scroll, wait, and pointer.
- `run_browser_burst` as a focused MCP tool with strict discriminated schemas.
- Per-step results/timings and explicit partial-failure reporting.
- Lazy debugger attachment reused within a burst and detached at completion.

## Safety boundaries

- Protocol remains version 1 and the extension ID remains `ohbbpamcljckmjhcpkcmefdobkoeaick`.
- The public allowlist increases from 24 to 25 primitives.
- Bursts cannot change tabs, navigate, open or close tabs, loop, branch, nest, or execute arbitrary code.
- Maximum eight steps, 12 seconds total, 256 KiB of results, and stop on the first failed step.
- Existing password, OTP, payment, file-upload, focused-tab, and viewport protections still apply locally.
