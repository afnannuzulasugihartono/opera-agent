# WHAT REACHED THE REGISTRY

**opera-agent-mcp 1.6.45 is the same code as 1.6.44, and it is published by
GitHub Actions itself.** The package carries no change in behaviour; the
change is in the identity the registry answers to. The npm half of the
trusted-publishing pair is now in place for this package
(`afnannuzulasugihartono/opera-agent`, workflow `publish-npm.yml`,
allowed to `npm publish`), created on 2026-11-12 and valid only if one
successful publish lands before 2026-11-14. This release is that publish.

**The extension stays at 1.6.44.** `extension/manifest.json` remains the
source of truth for what runs in the browser; nothing about the browser
build changed in 1.6.45, and no CRX or store artifact is cut for it. The
npm package simply stops pretending the browser did change.

# WHAT IT COSTS THE READER

Nothing. Installers see one more version in the list; the bits underneath
are the ones 1.6.44 already shipped, now with provenance attached.
