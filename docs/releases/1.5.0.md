# Opera Agent 1.5.0

Status: stable signed release under the established extension identity.

## Added

- Stable element identity for deduplicating lazy-loaded collections without replacing document-scoped action refs.
- Separate rendered `visible` and clipped/onscreen `inViewport` state.
- Viewport, document-size, device-scale, visual-scale, browser-zoom, and mutation metadata in existing observations.
- Actual scroll-container discovery plus before/after position, extent, movement, mutation, settling, and edge metrics.
- Directional `reachedBoundary` and an explicit `inputMethod` for wheel actions.
- A generic DOM fallback when an accepted background debugger wheel event cannot move an available container.

## Compatibility

- Protocol remains 1.
- The extension still advertises 26 allowlisted capabilities.
- The MCP server still exposes the same 18 named tools and unchanged input schemas. Existing ChatGPT connections do not need a newly discovered tool name for this checkpoint.
- No Google Maps-specific code is included in the extension.
