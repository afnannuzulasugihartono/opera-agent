# Opera Agent 1.5.0

Status: source development candidate for Milestone 4A; not yet the stable installed release.

## Added

- Stable element identity for deduplicating lazy-loaded collections without replacing document-scoped action refs.
- Separate rendered `visible` and clipped/onscreen `inViewport` state.
- Viewport, document-size, device-scale, visual-scale, browser-zoom, and mutation metadata in existing observations.
- Actual scroll-container discovery plus before/after position, extent, movement, mutation, settling, and edge metrics.
- Directional `reachedBoundary` and an explicit `inputMethod` for wheel actions.
- A generic DOM fallback when an accepted background debugger wheel event cannot move an available container.

## Compatibility

- Protocol remains 1.
- The extension still advertises 26 allowlisted capabilities.
- The MCP server still exposes the same 17 named tools and unchanged input schemas. Existing ChatGPT connections do not need a newly discovered tool name for this checkpoint.
- No Google Maps-specific code is included in the extension.

## Verification so far

- All Node unit/security/schema tests and static checks pass.
- The controlled Chromium extension suite passes, including a nested lazy-loaded feed where the first wheel discovers new content and correctly reports that the new boundary has not been reached, while the second wheel reaches the final boundary.
- The same complete suite passes in isolated real Opera under the established extension ID, with all 47 background-focus checks preserved.
- The fixture verifies stable-key persistence, clipped viewport state, debugger-to-DOM scroll fallback, reconnect/restart behavior, and active-tab/window preservation.

## Remaining production gate

- Build and sign the same-identity CRX.
- Install/update in the real Opera profile and verify a background Google Maps result panel plus at least two unrelated complex applications.
- Deploy and verify the updated MCP descriptions/instructions without changing its tool inventory.
