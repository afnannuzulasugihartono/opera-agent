# @last-edited: 2026-11-09 UTC+7.
# @title: 1.6.33 - no websocket at a dead bridge, and a second browser keeps its name.
# @state: the release note for the version now shipping.
# @dependencies: none.

The everyday browser shown on Brave's extensions page failed with
`WebSocket connection to 'ws://127.0.0.1:9451/' failed:` because, when no local
bridge is listening, the extension still tried to open a socket to a dead port.
Now the extension probes every candidate port before opening a WebSocket; when
nothing answers it records the miss and re-probes in five seconds instead of
firing a socket into a wall, so the errors page stays empty until there is a
bridge to connect to.

A second browser that connects and reconnects keeps its own namespace: the
loopback bridge now keys each browser's slot by its instance id rather than by
connection order, so a tab's namespaced id does not change every time the
extension drops and re-opens its socket.
