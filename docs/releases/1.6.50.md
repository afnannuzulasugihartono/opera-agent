# @state: the release note for the version the tree now reads.
# @dependencies: none.

# WHAT REACHED THE SURFACE

`dump_page` reads the page a caller names, not the page the user's window happens to hold. The MCP command now carries the tab the agent asked for into the relay, so the extension answers with evidence from that tab and never from a passerby neighborhood of whatever is focused.

# WHAT CHANGED FOR CALLERS

- `dump_page` with an explicit `tabId` always returns the content of that exact tab.
- `dump_page` without a `tabId` still falls back to the everyday visible tab in the user's own window, exactly as it did before.
- No other tool moved; nothing else changed.

# WHAT IT COSTS THE READER

None. This is a routing honesty fix: the agent sees what it asked to see, not what the user's cursor was near.
