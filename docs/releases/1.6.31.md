# @title: 1.6.31 — a second browser is a device, not a rejection.
# @state: the release note for the version now shipping.
# @dependencies: none.

Two browsers on one machine presented the same device name, so the second
one to pair replaced the first browser's token and the first was refused on
its next connection. A browser now keeps an identity of its own, sends it
in its handshake, and re-pairs as itself instead of displacing the other
one. The pairing no longer requires the name a code was minted with, so a
browser that already carries a suffixed name can re-pair with a fresh code.
