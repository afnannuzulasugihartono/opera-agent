# WHAT REACHED THE BROWSER

The driver runs on the person's own machine, at the speed of their browser rather
than the speed of a round trip.

The measurement that decided it: the same work done through the cloud cost two
network hops, and a CDP command over loopback costs less than a millisecond. The
browser was never the bottleneck, and the network hop was the whole cost. So the
local driver became a real thing — a CDP client that covers the Chromium family
(Chrome, Edge, Brave, Opera, Vivaldi and Chromium are one engine speaking one
protocol), an `opera-local` entry point with no dependencies so it runs on
someone else's machine, and a stdio MCP surface over it that advertises only the
nine tools the driver honestly does. A tool named and not honoured is a lie, so
the cloud's affordances are absent rather than listed as partial.

Two bugs the live run caught that the locks could not: every call was handed to
the serialiser without awaiting, so a pending call serialised as nothing and a
read came back empty; and the fake driver was synchronous, which is why the lock
passed. Both are locked now.

The device transport became push rather than poll. A six-step burst spent two
thirds of its time in transport rather than in the browser, because every action
paid two round trips and a blocking wait. One WebSocket now carries the command
down and the completion back up, and there is no polling fallback underneath: a
quiet fallback would restore the latency this removes while looking perfectly
healthy, which is worse than an outage because it is invisible.

# WHAT THIS RELEASE COULD NOT HAVE SHIPPED WITHOUT

A platform that kills the worker silently, and the proof that it was doing it.

Reloading the extension against the deployed bridge found three faults, and each
one looked like a healthy device from the outside. The worker was being closed:
a silent WebSocket is an idle service worker, and Chrome ends those, so the
device connected, reported ready, and died about every thirty seconds after. The
bridge now sends a frame on a timer — not polling, because it asks nothing and
waits for nothing, and it exists because an arriving message is what resets the
worker's timer.

The heartbeat was fighting the socket for the same state: it kept writing the
status the poll loop used to own, so a perfectly connected device reported
itself reconnecting. One field, one owner, now.

The worst of the three was a socket that looked open and was dead — held across
an edge instance being replaced, still receiving pings, with a subscription that
had died with the old instance. Every health signal read fine and no command
ever arrived. That is the failure this release exists to make impossible: a
one-way socket is now detected and thrown away rather than trusted.
