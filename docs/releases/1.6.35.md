# @title: 1.6.35 - the plan you are on is visible before it runs out, and the dashboard says so.
# @state: the release note for the version now shipping.
# @dependencies: none.

An account that spent its daily quota used to learn about it the same way every time: a refusal in the middle of a job, with nothing on screen that had warned it. This release puts the plan where a person already looks.

**`browser_status` carries the plan on both roads, success or failure.**

- The local loopback bridge's `browser_status` now passes each linked browser's meter through: `devices[].plan` with `plan`, `allowance`, `dailyQuota`, `usedToday`, `remaining` and `resetsAt` (the next UTC midnight), and a top-level `planExhausted: true` with `planExhaustedDevices: <names>` when any linked browser is at zero.
- The hosted MCP's `browser_status` (`opera-agent-mcp`) merged `plan/planStatus/planQuota/planUsed` only on a **successful** command — exactly the moment the plan ran out and the command failed, the answer carried no plan at all. `planInfo` now also answers `planRemaining` and `planExhausted`, and `executeStatus` merges it on the failure path too.
- No quota, gate, billing or wallet logic changed. The plan is read from `opera_my_plan`, the same RPC that already existed for the bridge.

**The dashboard is rebuilt around that number.**

- Ringkasan opens with the plan hero: the plan name, its status chip, how many commands are left today in large type, a progress bar of `usedToday / dailyQuota`, the session allowance and when the quota resets (UTC midnight). At zero the banner reads "Plan habis — reset besok 00.00 UTC" with a link to `/harga`.
- The rail is grouped: **Pelanggan** (Ringkasan, Device, Riwayat, Aksi, Saldo, Pairing, Akun) is what a client opens the console for; **Operator** (Tabel, Dengar) sits behind one labelled disclosure door, and a deep link to `#tabel` or `#dengar` opens the door itself.
- The whole page now reads in both Bahasa Indonesia and English: static strings through an `en` dict per the site's doctrine (authored Indonesian is the source of truth), the strings this module builds through a local dual-language dictionary, and flipping ID/EN re-renders them in place.
- Colour rides the data only — the bar and the exhausted state carry the accent and the danger; chrome is flat, hairlines separate surfaces, and figures are tabular.

**Limits, honestly.** The signed-in view is verified by whoever owns the account; every check available here ran without one (unit suites, the contract hash gate, the CSP hash gate, a local mock Supabase driven through a CDP-pointed Chrome for the firm, exhausted and unreadable-plan states, phone width, deep link into the operator door, and both languages). The hosted `browser_status` command itself was observed to answer `AWAIT_OUTCOME_UNKNOWN` on this account before this release and that road needs a command that can prove otherwise — it is tracked, not claimed fixed.

An account can now answer the only question the dashboard exists for — *is this browser still allowed to work today?* — without tabbing to a pricing page.
