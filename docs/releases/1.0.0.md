# Opera Agent 1.0.0

Release date: **2026-09-08**

## Highlights

- Clean rebuild under the product name **Opera Agent**.
- Thin MV3 local-browser bridge with 23 generic, allowlisted primitives.
- Versioned Supabase workflow registry with history and rollback.
- Bounded semantic chunks up to 12,000 characters instead of the legacy 2,400-character explicit-read cap.
- Rich ARIA/control state and trusted debugger/CDP input.
- Command path designed without the legacy synchronous outbound HTTP helper timeout.
- Signed CRX3 distribution with stable extension identity.
- Supabase-hosted update manifest/CRX service for private core updates.
- Automated cloud, protocol, security, reconnect, browser-restart, and Chromium regressions.

## Distribution

The signed 1.0.0 CRX is served by the production update service. The first install/pair remains a one-time browser trust step. After pairing, high-level automation changes normally ship as Supabase workflow updates without reinstalling the extension.

## Target-specific note

Off-store extension installation/update policy can differ between Chromium and Opera on Windows. The managed Chromium path is verified; the actual Opera installation is the final environment-specific acceptance layer.
