# WHAT REACHED THE BROWSER

**The extension is not ramping.** The popup asked the browser which size to
open at and let it guess, and the guess came out narrow — the topbar
wrapped "Opera Agent" onto two lines. Both pages and the base document now
pin 400px from one end to the other; the panel cannot collapse.

**A release now nudges the devices that carry it.** Publishing the CRX still
makes the release available through `update.xml` and the zip; on top of
that, the publish step now enqueues one `extension.update` command per
paired device, and every device that is online picks it up within seconds —
the same command the agent sends, so the device verifies the served build,
writes it over the allowed folder and restarts. Devices that were asleep get
it the moment they wake, from the same backstop alarm the extension already
runs. Nothing about the reader's one folder-allowance changes; the push just
removes the waiting.

# WHY THIS IS WORTH A RELEASE
# A version that travels by polling stays behind the newest one for as long
# as the poll is away. The release now travels on the same channel the
# browser uses for everything else, so the published build reaches the two
# paired browsers in seconds instead of half an hour.

# WHAT IT COSTS THE READER
# Nothing new. The one folder permission is the same one 1.6.41 asked for.
# This release is itself small; it exists so the next one is not a ritual.
