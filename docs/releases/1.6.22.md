# WHAT REACHED THE BROWSER

The service worker is no longer one file. `background.js` became eleven modules
under `extension/worker/` — action-focus, burst, capture, capture-page,
execute-pull, listen, loop-engine, private-tabs, tab-content, utils and
watch-registry — so a change to the loop no longer risks the dispatcher, and
the boundary that used to be a comment is now a file the tests can lock.

Three defects went with it, all measured rather than suspected:

- **Two floating promises.** `heartbeat().finally(...)` in the dispatcher and
  `loopTick(...)` in the loop engine were discarded. A rejection there vanished
  with no trace at all, which is why a heartbeat that stopped was invisible and
  a loop that died mid-task looked like a device that went quiet. Both now land
  on a warning that says which one failed.
- **`connectionState` could be reassigned.** It was `export let`, so a stray
  assignment anywhere would have replaced the whole state object instead of
  updating it, and every reader would silently follow the new one.
- **The state-bridge listener trusted a tag.** It accepted any `message` event
  carrying `source: 'opera-agent-state'`. It now checks that the event came
  from this document's own origin, and that the type is one of the seven the
  bridge actually sends — duck-start, duck-end, game-over, heartbeat, jump,
  started, stopped. Anything else never reaches the state it feeds.

That last one is the security change, and it is proven end to end rather than
argued: `tests/loop_state_drive.py` loads the packed extension into a real
browser, pairs it, opens the t-rex runner and plays it through the loop. The
run this release shipped on ended at 3133 ticks, 14 jumps and 50 delivered
events, every one of them carrying a type from that allowlist.

# WHAT REACHED THE SITE

English and Indonesian, on one shared mechanism. `landing/i18n.js` drives both
languages across every page except the legal bodies, and the login gate splits
into Facebook, sign-in and register on separate surfaces instead of one form
asking three questions at once.

The download hub became a single page with per-browser format pages behind it,
pinned to live Steam and VS Code figures rather than a hand-kept table. Every
page now carries a header comment the blank-line rule can read, which is why
this release also touches `_headers`: the inline scripts moved, so the sha256
hashes naming them in the CSP moved with them. `landing-hosting.test.mjs`
recomputes every one of those hashes from the HTML and fails if a page and its
policy ever disagree, so a page cannot deploy ahead of the policy that lets it
run.

# WHAT THIS RELEASE COULD NOT HAVE SHIPPED WITHOUT

The comment-spacing scanner was reading three languages as if they were strings.
A regex literal holding a quote, the body of a `<script>` tag, and a shell
string inside a YAML `run:` block each opened a region the scanner never left,
so every comment behind it was invisible to the blank-line rule. 626 comments
across the tree were being skipped while the rule reported the whole repository
clean. An interpolation (`${name}`) did the same thing to a fourth classifier
and had been doing it since the rule was written.

Fixing that is what turned this release into a quality-gate release. The rule
started finding what it had been missing, and the SonarCloud gate on the merge
that carried this code read 3.0% duplication on new code against a 3.0%
threshold. It closed at 2.9798%, and it closed by removing repetition rather
than by moving the threshold: the assertion that used to be written out once
per case now exists once.
