# @title: 1.6.32 - the everyday browser names itself to the meter.
# @state: the release note for the version now shipping.
# @dependencies: none.

The loopback bridge now meters every session against the account that owns
the browser, which takes one thing the everyday browser was not sending: its
device token. The loopback hello now carries the paired device credentials and
the extension's own version, alongside the instance id it already had, so the
bridge can meter the session instead of refusing it. A paired browser is
metered against its account; a browser that is not paired is refused with the
reason, which is the honest answer for an unmetered drive - pair it in the
dashboard to use the local drive.
