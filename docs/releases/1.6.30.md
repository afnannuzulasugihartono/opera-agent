# @title: 1.6.30 — a full-page capture that comes back in time to be read.
# @state: the release note for the version now shipping.
# @dependencies: none.

A document taller than a screen needs one capture per strip, and thirty-three
strips do not fit in the thirty seconds one command may take. The slice now
stops at sixty percent of its budget and says what it did not reach, so the
answer arrives while there is still time to carry it, and the rest is one tile
offset away.
