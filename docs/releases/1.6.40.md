# WHAT REACHED THE BROWSER

**Brave is told the truth instead of a JavaScript error.** Brave hides the File
System Access API behind a flag, so the folder permission the automatic update
needs simply does not exist there - the reader pressed the button and the
browser answered with `showDirectoryPicker is not defined`, which says nothing
about what to do.

The refusal now names the way out: `brave://flags`, search
`file-system-access-api`, set it to Enabled, relaunch. Chrome, Edge, Opera and
Vivaldi carry the API and need nothing.

# WHY THIS IS WORTH A RELEASE
# The feature was already there and already worked wherever the browser allows it.
# What was missing was the sentence that tells a reader on the one browser that hides it what to press.
