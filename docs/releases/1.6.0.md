# Opera Agent 1.6.0

Status: signed semantic-runtime candidate under the established extension identity;
production activation and normal-profile acceptance are pending.

## Added

- Document-scoped logical identity for rich page observations, with deterministic
  rerender matching, explicit ambiguity, bounded caches, and safe resets.
- Bounded `INSERT`, `UPDATE`, `REMOVE`, `MOVE`, `RESET`, and
  `NO_RELEVANT_CHANGE` semantic deltas.
- Generic materialized views for landmarks, forms, dialogs, repeated regions,
  document structure, and measured scroll containers without site-specific code.
- Causal view invalidation, observation provenance, and scoped completion results
  using `PROVED`, `BOUNDED_COMPLETE`, `PARTIAL`, `BLOCKED`, and `UNKNOWN`.

## Compatibility and safety

- Protocol remains 1 with the same 26 capabilities and 18 MCP tools.
- MCP source, tool names, and input schemas are byte-for-byte unchanged.
- Semantic fields are optional additions to rich `page.read`; existing refs remain
  the only action handles.
- Action success cannot create `PROVED` evidence.
- Sensitive values, screenshots, page text, and private URLs are not retained by
  semantic caches or benchmark output.

## Candidate verification

- Static validation and all 74 Node tests pass.
- A deterministic 250-step mutation fuzz run passes bounds, uniqueness, eviction,
  reset, isolation, and false-proof checks.
- Controlled Chromium and isolated Opera 135 pass the full browser suite,
  reconnect/restart checks, private/sensitive capture checks, 20/20 burst
  stability, and foreground-focus preservation.
- Three controlled runs produce a 19.83 ms median rich read, about 5.6% above the
  paired 18.78 ms accepted baseline and below the 15% gate. Focus changes and
  persisted sensitive values remain zero; delta/snapshot ratio is 12%.
- Production backend preflight reports the stable 1.5.2 device online with
  protocol 1 and 26 capabilities. OAuth/health endpoints pass, the cloud self-test
  returns `cloud-ok`, and transactional idempotency/timeout probes pass.
