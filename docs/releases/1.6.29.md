# @title: 1.6.29 — a full-page capture that survives the whole document.
# @state: the release note for the version now shipping.
# @dependencies: none.

A full-page capture of a document taller than a screen needs one capture per
viewport-height strip, and the device used to kill the job at ten seconds -
before the first strip of a long page was done. The capture now gets the whole
thirty seconds the caller allowed, and a slice stops near the deadline and
reports what it did not reach, so the rest is one tile offset away.
