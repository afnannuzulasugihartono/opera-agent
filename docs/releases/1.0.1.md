# Opera Agent 1.0.1

Opera Agent 1.0.1 is the first release accepted end-to-end on the user's real Opera installation.

## Highlights

- Durable command-completion persistence and bounded retry/backoff.
- Two-phase `opera_run()` compatibility API so queued commands are committed before the browser consumes them.
- Asynchronous `opera-agent-runner` for server-side workflows.
- Stable extension ID `pagjlnohdemoohcncicjmaejedcmcocm`.
- Protocol version remains `1`; all 23 browser primitives remain available.

## Real Opera acceptance

Verified on the installed signed CRX:

- pairing and heartbeat;
- `browser.ping` after restart and after update;
- tab list/open/activate/close;
- trusted debugger/CDP click transport;
- semantic page reads in 6,000-character chunks with continuation to 12,000;
- ARIA state including YouTube captions reporting `ariaPressed="true"`;
- YouTube media-state extraction;
- browser restart reconnect with pairing preserved;
- signed self-hosted update from `1.0.0` to `1.0.1`, same extension ID, pairing preserved, and post-update commands successful.
