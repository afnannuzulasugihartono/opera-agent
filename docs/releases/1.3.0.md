# Opera Agent 1.3.0

Status: signed same-identity release candidate staged inactive; 1.2.0 remains active until installed-Opera acceptance begins.

## Highlights

- Normal coordinate input can run invisibly against an explicit inactive target tab without activating it.
- Trusted text insertion works in normal inputs and contenteditable editors through CDP.
- The visible pointer remains an explicit foreground diagnostic and never silently takes focus.

## Safety boundaries

- Protocol remains version 1 with the same 25 allowlisted primitives.
- Extension identity remains `ohbbpamcljckmjhcpkcmefdobkoeaick` and the existing pairing must be preserved during update.
- Every multi-step action remains pinned to one explicit `tabId`.
- Password, OTP, payment, file-upload, internal-page, viewport, timeout, and output-size protections remain enforced locally.
- A foreground pointer requested against an inactive tab returns structured `FOREGROUND_REQUIRED` instead of activating the tab.
