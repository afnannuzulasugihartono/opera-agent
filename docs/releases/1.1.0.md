# Opera Agent 1.1.0

Status: source candidate; not published as a production extension.

## Highlights

- Text-only `page.read` responses for high-volume reading.
- Internal zero-payload content readiness checks.
- Generic no-op tab activation and navigation fast paths.
- Bounded metadata-only workflow performance telemetry.
- Protocol 1, 23 public primitives, and the established extension identity are retained.

## Added

- `includeElements:false` on `page.read`; default behavior remains unchanged.
- Versioned workflow revisions for full-page and transcript reads.
- Dynamic-port browser regression with explicit installed-Opera support.

## Security

- No `eval`, `new Function`, or remotely supplied executable JavaScript.
- Password, PIN, OTP, 2FA, CVV/CVC, security-code, and file-upload protections remain enforced.
- Telemetry records timings, counts, statuses, method names, and bounded byte-count samples only; it does not record page text or form values.

## Compatibility

- Protocol remains `1`.
- Public method allowlist remains at 23 methods.
- Existing element-rich `page.read` callers are unchanged unless they opt into `includeElements:false`.
- Revised workflows retain `maxElements:1`, so extension 1.0.1 keeps its previous bounded fallback while ignoring the new flag.
- Historical workflow versions and legacy release documentation remain available.

## Verification completed

- Node protocol/workflow/security tests.
- Static validation on Windows.
- Real installed Opera regression using a temporary profile and the established extension ID.
- Production runner v6 deployment and workflow migration, with bounded telemetry sampling, 1.0.1 fallback, and prior workflow versions verified.
