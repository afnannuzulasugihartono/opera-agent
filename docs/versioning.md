# Versioning

Opera Agent uses Semantic Versioning:

```text
MAJOR.MINOR.PATCH
```

Examples:

- `1.0.0` — first stable release
- `1.0.1` — bug fix
- `1.1.0` — backward-compatible feature
- `2.0.0` — breaking change

Pre-release versions may use standard identifiers:

- `1.0.0-beta.1`
- `1.0.0-rc.1`

Stable releases should not use names such as `FINAL`, `FINAL2`, or internal build counters in the user-facing version.

The rebuilt project starts a clean version line at **1.0.0**. Previous Local Opera Agent v3 builds remain legacy history only.
