Troubleshooting

  • Install: load the unpacked extension from opera://extensions and accept the requested permissions, including debugger access for trusted input.
  • Pairing: pairing rejected? Generate a fresh one-time pairing value from the connected Supabase project, then pair again from the popup.
  • Bridge override: an https:// address here overrides the default bridge; leave the field empty and save to reset to the default.
  • Log level: debug, warn, or error — debug is the most verbose and the default is warn.
  • Self-test: run self-test from the popup to probe the bridge, then read the connection line.
