Tetap di device ini

 

 

Endpoint dan nama model tetap di browser ini dan tidak pernah dikirim ke bridge Opera Agent. Kunci dimasukkan di popup, di samping pairing, karena secret tidak pantas ada di halaman ini.

Bantuan

  • Pasang: muat extension tanpa paket dari opera://extensions dan terima izin yang diminta, termasuk akses debugger untuk input terpercaya.
  • Pairing: pairing ditolak? Buat kode pairing sekali pakai yang baru di Dashboard → Pairing manual, lalu pairing lagi dari popup.
  • Bridge: alamat https:// di sini menimpa bridge bawaan; kosongkan lalu simpan untuk kembali ke bawaan.
  • Level log: debug, warn, atau error — debug paling berisik dan bawaannya warn.
  • Uji mandiri: jalankan uji mandiri dari popup untuk memeriksa bridge, lalu baca baris koneksi.
