# One product, two roads, one browser half

Opera Agent is one product with two delivery roads and a single browser half both roads terminate in. The 42 tools are the same 42 on both roads; any module both roads need lives once in `shared/` — never copied by hand.

```
  HOSTED ROAD (Supabase)                LOCAL ROAD (npm)
  MCP client anywhere                   MCP client on this machine
        |  HTTP / SSE                          |  stdio
        v                                       v
  hosted/ (config.toml, migrations/,      local/ (bin/opera-local.js)
    functions/ — 9 edge functions,           42 tools, same protocol, same parser
    _shared/ — edge-runtime modules)         CDP ⇄ local/ or bridge ⇄ extension/
        |  relay (opera-agent-bridge)            |
        v                                       v
  ________________________________________________________
  extension/ — the MV3 browser both roads terminate in
  (protocol.js is the wire truth; no second copy exists)
  ________________________________________________________
```

# What may import what (enforced)

| Folder | May import | May not import |
|---|---|---|
| `extension/` | `extension/` only | `shared/`, `hosted/`, `local/`, anything outside |
| `local/` | `local/` (`./lib/` generated) | anything outside `local/` |
| `hosted/functions/**` | `hosted/`, `../../../shared/*`, builtins | `local/`, `extension/` |
| `shared/` | `shared/`, builtins | anything else |
| `tests/`, `scripts/` | anything | — |

`tests/tooling/architecture.test.mjs` enforces this matrix, and fails if a path this file names does not exist.

# Where a new file goes

1. Needed by both roads, no I/O → `shared/` (plus one line in `shared/README.md`)
2. Edge-runtime only → `hosted/functions/_shared/`
3. A new wire method → `extension/lib/protocol.js` only
4. A new test → the `tests/<subject>/` folder matching its area; never `tests/` root
5. A new script → the verb group it belongs to; register it in `package.json`
6. Anything new at repository root → refused. This file and the gate fail the build.

# The one source, two roads rule

The two roads share either the **source** (exactly one file in the tree) or a **generated copy**. They never share a hand-written copy. When a module is both roads' concern:

- Write it once in `shared/`. The hosted road imports it directly (Deno static import). The local road gets a byte copy at pack time (`scripts/pack/pack-mcp.mjs`), generated fresh, never hand-edited, never committed.
- The protocol is the same idea one level down: `extension/lib/protocol.js` is the only file with the wire contract, and `extension/` and the relay both read it by import.
- If you are about to hand-write `local/lib/<anything>` or copy `shared/` into `extension/`, stop. That is the failure mode this file exists to make impossible.

# If the map and the tree disagree

Stop and fix the map, never the test. If a file moves, update this file in the same commit. If a new directory appears that this file does not name, the build fails.
