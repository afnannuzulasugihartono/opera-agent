Pasang extension

  1. Unduh. Ambil arsip .zip dari halaman Unduh.
  2. Ekstrak. Ke folder yang tidak akan kamu rapikan lagi, misalnya C:\OperaAgent\.
  3. Muat. Buka chrome://extensions (Edge: edge://extensions, Brave: brave://extensions, Opera: opera://extensions), nyalakan Mode Pengembang, lalu muat folder tadi.
  4. Periksa. Opera Agent muncul di daftar extension.

Mesin yang dikelola perusahaan memasang .crx bertanda tangan lewat chrome://policy. Firefox tidak didukung: tidak ada izin debugger di sana.

Pemasangan tidak dipungut biaya. Yang dibayar nanti adalah setiap pekerjaan yang selesai.

Masuk dan pair device

Masuk dengan magic link email, Google, atau GitHub dari halaman Masuk.

  1. Buat kode. Di Dashboard, buka Pairing dan buat kode sekali pakai.
  2. Tempel. Kode berlaku sepuluh menit dan hanya dipakai sekali.
  3. Periksa. Device muncul di daftar dengan status daring.

Device yang tidak dikenali bisa dicabut kapan saja di Dashboard.

Tugas pertama

Anda bicara, browser bekerja, hasilnya menjadi artefak nyata. Contoh: Buka Google Maps, cari kopi dekat Monas, dan tulis hasilnya ke sheet.

  • Satu pekerjaan berarti satu hasil: satu halaman, satu laporan, atau satu daftar.
  • Jumlah aksinya dibatasi. Perkiraan yang lebih besar ditolak di depan dengan tawaran dipecah, bukan gagal di tengah. Batas dan harganya ada di halaman Harga.
  • Konten halaman hanya pergi ke endpoint model Anda; kunci API tersimpan di browser ini.

Berkas yang jadi

Satu pekerjaan berakhir sebagai berkas yang bisa langsung dibuka. Empat contoh nyata dari perusahaan tiruan, diunduh apa adanya:

  • Laporan keuangan September 2026 — Excel: baris laporan, baris sumber angkanya, dan buku besar yang menyebut baris mana yang menghasilkan tiap angka.
  • Rencana strategis 2027 — PowerPoint: satu sampul dan empat slide isi, dan tiap angka di slide berasal dari laporan yang sudah dicek.
  • Riset promo — Word: judul, bagian, tabel, dan grafik.
  • Rencana pemasaran 2027 — Word: positioning, segmentasi, dan rencana kanal.

Portal yang minta masuk tidak menghentikan pekerjaan: agen membaca halaman lebih dulu, tahu ada sign-in atau captcha, dan menunggu Anda menyelesaikannya di browser Anda sendiri sebelum lanjut di tab yang sama.

Cara file-file itu dibuat dari satu file kas ada di halaman Studi kasus.

Saldo dan tagihan

Isi saldo lewat QRIS dari Dashboard, tanpa langganan. Saldo yang kurang membuat pekerjaan ditolak sebelum mulai, dengan tautan isi ulang. Harga tetap, pengembalian, dan masa berlaku saldo ada di halaman Harga.

Tools MCP

56 tool di atas 36 primitive browser. Tugas masing-masing:

Peramban

browser_status
Apakah ekstensi daring, device mana yang dipakai, dan kemampuannya.
list_tabs
Daftar tab yang terbuka, dengan id, judul, URL, dan status muatnya.
open_url
Buka URL di tab background; aktif hanya saat Anda minta.
activate_tab
Aktifkan sebuah tab; hanya saat Anda melihat atau mengizinkan.
navigate_tab
Navigasi tab tertentu ke URL, tanpa dipindah ke depan.
close_tab
Tutup tab berdasarkan ID, hanya bila Anda yang memintanya.

Halaman (membaca)

read_page
Default: observasi padat tugas (teks, elemen interaktif dengan ref, fakta viewport). Dengan view: "map": peta seluruh halaman dalam 17 kelas, koordinat dokumen, ref bertahan saat scroll.
capture_page
JPEG terbatas dari tab tertentu; bisa satu halaman penuh lewat tile.
record_start
Merekam tab ke webm di folder Downloads; setelah dipanggil, semua perintah berjalan seperti biasa (klik, isi, scroll, burst) dan semuanya tertangkap. Ditolak di permukaan sensitif seperti capture_page.
record_stop
Mengakhiri rekaman dan menulis webm ke folder Downloads; mengembalikan manifest (nama berkas, byte, frame) dan sampai empat still sebagai gambar.
scan_page
Satu berkas HTML berdiri sendiri di folder Downloads: DOM hasil render terakhir, stylesheet dan script di-inline, gambar/ikon/font sebagai data-URL — struktur internal situs untuk analisis offline. Ditolak di permukaan sensitif seperti capture_page.
find_elements
Cari elemen interaktif lewat teks, peran ARIA, atau tag; hasilnya punya ref untuk klik dan isi.

Aksi

click_element
Klik ref memakai input tepercaya; background secara default.
fill_element
Isi kolom teks lewat ref; ditolak di password, OTP, pembayaran, dan upload.
press_key
Kirim tombol (Ctrl+A, Ctrl+V, Enter…) atau ketik teks ke permukaan terfokus.
stream_keys
Rangkaian chord dan teks dalam satu panggilan, seperti melintasi menu.
scroll_page
Scroll relatif atau absolut di halaman tanpa memindah fokus.
pointer
Satu pointer untuk move, click, drag, wheel, dan hover untuk menu.
run_browser_burst
1–8 aksi bergantung dalam satu panggilan; tanpa JavaScript bebas; 12 detik.
run_workflow
Workflow situs tertentu yang terdaftar, misalnya youtube.skip_ads.
run_program
Program baca saja yang diverifikasi di dalam VM; tanpa langkah tulis.
run_adhoc
Workflow tulis sementara (cari → isi → klik → verifikasi), dihapus setelah jalan.

Otomatisasi dan memori

start_watch
Pasang trigger lokal di tab; saat kondisi terpenuhi, aksi jalan lokal, tanpa bolak-balik model.
wait_events
Long-poll untuk event dari trigger; hasil terbaru pertama dengan cursor.
stop_watch
Matikan satu trigger berdasarkan id, atau semua trigger aktif.
skill_save
Simpan pelajaran tugas ke memori bersama lintas akun.
skill_recall
Cari pelajaran dari tugas yang mirip; tiap pelajaran punya tugas, situs, dan jebakan.

Media

media_state
Laporan elemen audio/video di halaman: kehadiran, waktu, durasi, mute, volume.
media_play
Mulai pemutaran; jika diblokir browser, tekan Play lewat click_element.
media_pause
Jeda pemutaran.
media_seek
Lompat ke detik tertentu; nilai di luar durasi dikecilkan.
media_stream_start
Mulai sesi dengar: audio halaman disadap dan ditranskripsi per jendela.
media_stream_stop
Hentikan sesi dengar; ekor terakhir ikut ditranskripsi.
media_listen_read
Baca segmen transkrip dengan cursor; transkrip tidak pernah masuk dashboard.

Rute

use_browser
Kunci provider ini ke satu browser untuk semua panggilan berikutnya (mis. opencode di Brave, Claude di Chrome). Tanpa argumen: baca pin sekarang dan browser yang awake; any: lepas kuncinya, freshest awake menjawab; header X-Opera-Device pada satu panggilan selalu menang atas pin.

Pin disimpan per (akun, provider); provider lain tidak ikut pindah.

Kas

statement_deliver
Unduh statement klien untuk bulan tertentu ke disk Anda, di bawah nama yang Anda pilih; pengiriman kedua untuk bulan sama ditolak.
statement_manifest
Baca manifest yang disimpan device: satu baris per statement terkirim, beserta ukuran, jenis, jumlah halaman, dan saldo penutup.
invoice_create
Susun invoice dari baris manifest atau client-periodes; amount dari price list, bukan dari angka di panggilan.

Tiga di atas untuk paket tutup buku; sisanya untuk semua plan.

Hubungkan AI harness

Satu server MCP per mesin: driver lokal, jalan di mesin Anda sendiri, tanpa biaya per panggilan dan tanpa melewati server orang lain.

Pasang driver lokal — panduan lengkap per harness, termasuk cara pasang dari terminal dan prompt yang bisa ditempel ke AI Anda.

Koneksi driver lokal:

npx -y opera-agent-mcp local

OpenCode

Tambah ke opencode.json:

{
  "mcp": {
    "opera-agent": {
      "type": "local",
      "command": "opera-agent-mcp",
      "args": ["local"]
    }
  }
}

Kilo Code

Tambah ke MCP settings (JSON):

{
  "mcpServers": {
    "opera-agent": {
      "command": "opera-agent-mcp",
      "args": ["local"]
    }
  }
}

Claude Desktop

Dialog konfig (Settings → MCP → Add local server):

command: npx
args: ["-y", "opera-agent-mcp", "local"]

Server lokal menambah 56 tool di atas 36 primitive browser.

Tidak perlu login atau langganan untuk memakai driver lokal. Meter plan tetap jalan di bridge — sisa quota Anda bisa dilihat dengan opera-agent-mcp doctor kapan pun. Semua jalur dijelaskan di satu panduan: docs/agent-call.md.

ChatGPT dan konektor lain

Konektor mereka bicara remote-over-HTTP; itu sudah berhenti eksis — kami tidak menyediakan jalur hosted lagi. Untuk ChatGPT dan harness serupa, gunakan harness lokal (atau Claude Desktop/OpenCode yang menerima MCP stdio).

Setelah terpasang, alat baru muncul sesudah restart harness — itu perilaku harness, bukan error koneksi.

Batas yang dijaga

  • Password, kode sekali pakai, PIN, kartu, dan CVV selalu ditolak. Pekerjaan yang berhenti di situ gagal.
  • Tab private: screenshot ditolak. Tab non-http(s): primitive menolak.
  • Enam izin: tabs, scripting, storage, alarms, debugger, downloads. Satu alasan untuk tiap izin ada di halaman Unduh.
  • Yang masuk ke server untuk penagihan hanya: id reservasi, jenis tugas, status, dan hash artefak. Isi halaman tidak pernah ikut.
