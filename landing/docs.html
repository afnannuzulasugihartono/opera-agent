Pasang, pair, jalankan, hubungkan.

Pasang extension

  1. Unduh. Ambil arsip .zip dari halaman Unduh.
  2. Ekstrak. Ke folder yang tidak akan kamu rapikan lagi, misalnya C:\OperaAgent\.
  3. Muat. Buka chrome://extensions (Edge: edge://extensions, Brave: brave://extensions, Opera: opera://extensions), nyalakan Mode Pengembang, lalu muat folder tadi.
  4. Periksa. Opera Agent muncul di daftar extension.

Mesin yang dikelola perusahaan memasang .crx bertanda tangan lewat chrome://policy. Firefox tidak didukung: tidak ada izin debugger di sana.

Pemasangan tidak dipungut biaya. Yang dibayar nanti adalah setiap pekerjaan yang selesai.

Masuk dan pair device

Masuk dengan magic link email, Google, atau GitHub dari halaman Masuk.

  1. Buat kode. Di Dashboard, buka Pairing dan buat kode sekali pakai.
  2. Tempel. Kode berlaku sepuluh menit dan hanya dipakai sekali.
  3. Periksa. Device muncul di daftar dengan status daring.

Device yang tidak dikenali bisa dicabut kapan saja di Dashboard.

Tugas pertama

Anda bicara, browser bekerja, hasilnya menjadi artefak nyata. Contoh: Buka Google Maps, cari kopi dekat Monas, dan tulis hasilnya ke sheet.

  • Satu pekerjaan berarti satu hasil: satu halaman, satu laporan, atau satu daftar.
  • Jumlah aksinya dibatasi. Perkiraan yang lebih besar ditolak di depan dengan tawaran dipecah, bukan gagal di tengah. Batas dan harganya ada di halaman Harga.
  • Konten halaman hanya pergi ke endpoint model Anda; kunci API tersimpan di browser ini.

Saldo dan tagihan

Isi saldo lewat QRIS dari Dashboard, tanpa langganan. Saldo yang kurang membuat pekerjaan ditolak sebelum mulai, dengan tautan isi ulang. Harga tetap, pengembalian, dan masa berlaku saldo ada di halaman Harga.

Hubungkan AI harness

Server MCP untuk OpenCode, Kilo Code, Claude Code, dan konektor lain. Masuk dengan akun Anda (OAuth).

Server MCP:

https://nenmkmtvjremqphfqnfw.supabase.co/functions/v1/opera-agent-mcp

OpenCode

Tambah ke opencode.json, ganti opera dengan nama device Anda:

{
  "mcp": {
    "opera-agent": {
      "type": "remote",
      "url": "https://nenmkmtvjremqphfqnfw.supabase.co/functions/v1/opera-agent-mcp",
      "oauth": { "clientId": "bbc5eb76-f385-435b-8b13-8e339b45e633" },
      "headers": {
        "X-Opera-Device": "opera",
        "X-Opera-Provider": "opencode",
        "x-region": "ap-southeast-1"
      }
    }
  }
}

Kilo Code

Tambah ke MCP settings (JSON), ganti opera dengan nama device Anda:

{
  "mcpServers": {
    "opera-agent": {
      "url": "https://nenmkmtvjremqphfqnfw.supabase.co/functions/v1/opera-agent-mcp",
      "headers": {
        "X-Opera-Device": "opera",
        "X-Opera-Provider": "kilo",
        "x-region": "ap-southeast-1"
      }
    }
  }
}

Claude Code

Di terminal, ganti opera dengan nama device Anda:

claude mcp add --transport http opera-agent https://nenmkmtvjremqphfqnfw.supabase.co/functions/v1/opera-agent-mcp --header "X-Opera-Device: opera" --header "X-Opera-Provider: claude" --header "x-region: ap-southeast-1"

Server itu menambah 34 tool di atas 31 primitive browser.

ChatGPT dan konektor lain

Cukup URL server di atas plus OAuth. Server memakai device pertama milik akun Anda dan menebak provider-nya. Untuk device lain, pair ulang.

Setelah terpasang: buka pengaturan konektor, pilih Allow all tools, lalu refresh atau buka chat baru. Daftar tool baru muncul sesudah itu — itu perilaku ChatGPT, bukan error koneksi.

Batas yang dijaga

  • Password, kode sekali pakai, PIN, kartu, dan CVV selalu ditolak. Pekerjaan yang berhenti di situ gagal.
  • Tab private: screenshot ditolak. Tab non-http(s): primitive menolak.
  • Enam izin: tabs, scripting, storage, alarms, debugger, downloads. Satu alasan untuk tiap izin ada di halaman Unduh.
  • Yang masuk ke server untuk penagihan hanya: id reservasi, jenis tugas, status, dan hash artefak. Isi halaman tidak pernah ikut.
