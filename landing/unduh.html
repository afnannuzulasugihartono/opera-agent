01Unduh arsip

Tekan tombol di atas. Berkas opera-agent.zip tersimpan ke folder Unduhan.

02Ekstrak ke folder tetap

Unzip opera-agent.zip ke folder yang tidak akan kamu rapikan lagi, misalnya C:\OperaAgent\.

03Buka halaman extension

chrome://extensions di Chrome, edge://extensions di Edge, opera://extensions di Opera dan Vivaldi.

04Aktifkan mode pengembang

Toggle di pojok kanan atas, lalu Load unpacked dan pilih folder hasil ekstrak.

05Pair dari Dashboard

Buka Dashboard, klik Pair device, tempel kode 10 menit di popup extension.

+Izin, dengan alasan jelas.
tabs
Membuka dan menavigasi tab.
scripting
Menjaga content script tetap hidup.
storage
Menyimpan token dan setelan lokal.
alarms
Menjaga polling tetap berjalan.
debugger
Klik terpercaya, screenshot, dan aksesibilitas.
downloads
Menyimpan dan membuktikan berkas yang diunduh.

Host permission berlaku di semua asal — kamu yang menentukan halaman. Screenshot ditolak di tab private, dan field password, OTP, PIN, kartu, serta CVV diblokir.

+Kenapa belum ada tombol pasang sekali klik

Extension dengan akses debugger harus lewat review Chrome Web Store. Sementara itu, pengguna pertama memuat sendiri, dan listing menyusul setelah review.

+Build lama & riwayat

Setiap rilis 1.6.x bertanda tangan tetap tersedia di GitHub Releases — .zip, .crx dan SHA256SUMS — untuk mesin enterprise.
