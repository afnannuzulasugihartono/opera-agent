Pasang Opera Agent 1.6.15

Jalankan pemasang, pilih browser, selesai. Tidak ada Chrome Web Store, tidak ada load unpacked, dan pembaruan berikutnya dipasang sendiri oleh browser.

Tiga langkah memasang

  1. Klik berkas di atas, lalu jalankan. Windows meminta izin administratif sekali; itu perlu karena browser hanya membaca kebijakan pemasangan dari lokasi yang dilindungi.
  2. Centang browser yang Anda pakai, lalu tekan Pasang.
  3. Tutup semua jendela browser, lalu buka lagi. Opera Agent terpasang saat browser mulai.

Kalau tidak muncul setelah dibuka

Buka chrome://policy di browser itu dan cari Opera Agent. Kalau halaman itu kosong, periksa juga chrome://extensions dan pastikan Mode Pengembang tidak perlu diaktifkan — pemasangan ini tidak memakainya.

Pasang manual

Kalau polityvek ditolak, unduh arsip dan muat sendiri. Berjalan di Brave dan Chrome.

Unduh opera-agent-1.6.15.zip

Verifikasi berkas

Bandingkan sidik jari di atas dengan berkas Anda. Di PowerShell: Get-FileHash .\OperaAgent-Installer.exe -Algorithm SHA256

Tiga langkah memasang

  1. Buka halaman extension. Ketik opera://extensions di bilah alamat, atau chrome://extensions di Chrome.
  2. Aktifkan mode pengembang. Toggle di pojok atas, lalu klik Load unpacked dan pilih folder hasil ekstrak arsip.
  3. Pasangkan device. Masuk ke Dashboard, buat kode pairing sekali pakai, lalu tempel di popup extension.

Izin yang diminta, dan kenapa

Lima izin, satu per satu. Tidak ada izin yang tidak dijelaskan.

tabs
URL dan judul tab, untuk membuka dan navigasi tab yang kamu beri perintah.
scripting
Menyuntikkan ulang content script setelah worker berhenti, dan memeriksa frame tersembunyi sebelum screenshot.
storage
Menyimpan device token, kode pairing, dan setelanmu di browser ini.
alarms
Menjaga loop polling hidup; MV3 mematikan worker saat idle.
debugger
Input Klik-terpercaya, screenshot, pohon aksesibilitas, dan simulasi fokus. Tanpa ini, halaman bisa menolak klik.

Host permission http://*/* dan https://*/* karena kamu yang menentukan halaman tujuan saat runtime, jadi daftar asal tidak bisa diketahui lebih dulu. Batas sesungguhnya ditegakkan di kode: setiap primitive menolak tab non-http(s), screenshot ditolak di tab private, dan field password, OTP, PIN, kartu, serta CVV diblokir.

Kenapa belum ada tombol pasang sekali klik

Extension dengan akses debugger harus lewat review Chrome Web Store. Sementara itu pengguna pertama memuat sendiri, dan listing menyusul setelah review.
