Install

The extension is the whole product on your machine. The server only carries commands to it.

  1. Load the extension. Open opera://extensions, turn on developer mode, and load the unpacked extension folder. A published build appears in the Chrome Web Store when the listing is approved.
  2. Pair it. Generate a one-time pairing value from the connected project, then paste it in the popup. Pairing is revocable one device at a time.
  3. Connect an assistant. Point your assistant at the MCP endpoint for the browser_* and read_page tools, or sign in on this page first.
  4. Check what it can see. The popup reports whether the tab is active and whether you are present, so an assistant can tell foreground from background before it acts.

Bring your own model

Paste the endpoint, model name and API key your provider gave you. This form talks to your installed extension and to nothing else: there is no server here to send it to. The key is stored in your browser and is never shown back to this page.

 

The extension accepts an https endpoint, or plain http on 127.0.0.1 for a model that runs on this machine. If the extension is not installed, use Copy instead and paste the values into the extension popup.

Sign in and let an assistant drive

Opera Agent speaks MCP, so any assistant that speaks MCP can drive it. Sign-in is handled by the project you connect to.

OAuth consent

Approving an assistant is one page and one scope. Nothing is granted until you press the button on it.

Tools

22 tools: burst actions, page reads, tabs, media, watch and wait. The 26 browser primitives underneath stay unchanged.

Human in the loop

Foreground mode needs permission every time. Passwords, one-time codes and payment fields are refused.

What leaves your machine

Stated plainly, because an assistant with browser access is worth trusting only if you know the answer.

Page content
Goes only to the model endpoint you configured above. Never to the Opera Agent bridge.
API key
Stored in this browser. Never uploaded, never rendered back into this page, never logged.
Commands
Enqueue and result travel through the project bridge, so an assistant can act on your device.
Screenshots
Refused on a page showing a password, one-time code or payment field, and refused in private and incognito tabs.
