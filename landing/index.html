Opera Agent Instalasi Model Anda Masuk Privasi AkunDashboard

Asisten Anda mengemudikan browser Anda.

Opera Agent memberi asisten AI yang sudah Anda pakai sebuah jembatan terkendali ke browser Anda sendiri: 26 aksi yang diizinkan, tanpa eksekusi skrip sembarangan, dan setiap aksi bisa Anda awasi. Anda membawa model sendiri. Konten halaman hanya pergi ke endpoint model Anda.

Instalasi Sambungkan model

Instalasi

Extension adalah seluruh produk di mesin Anda. Server hanya mengantar perintah ke sana.

  1. Muat extension. Buka opera://extensions, aktifkan developer mode, dan muat folder extension yang belum dipaket. Build tayang muncul di Chrome Web Store setelah listing disetujui.
  2. Pairing. Buat nilai pairing sekali pakai dari project yang tersambung, lalu tempel di popup. Satu device ter-pairing dalam satu waktu.
  3. Sambungkan asisten. Arahkan asisten Anda ke endpoint MCP untuk tools browser_* dan read_page.
  4. Periksa apa yang bisa dilihatnya. Popup melaporkan apakah tab aktif dan apakah Anda ada, sehingga asisten tahu beda foreground dan background sebelum bertindak.

Bawa model sendiri

Tempel endpoint, nama model, dan kunci API dari penyedia Anda. Formulir ini hanya bicara ke extension yang terpasang: tidak ada server di sini yang bisa dikirimi. Kunci tersimpan di browser Anda dan tidak pernah ditampilkan kembali ke halaman ini.

 

Extension menerima endpoint https, atau http polos di 127.0.0.1 untuk model yang berjalan di mesin ini. Bila extension belum terpasang, gunakan Salin saja lalu tempel nilainya di popup extension.

Masuk dan biarkan asisten bekerja

Opera Agent bicara MCP, sehingga asisten apa pun yang bicara MCP bisa mengemudikannya. Sign-in diurus oleh project yang Anda sambungkan.

Masuk / Daftar

Persetujuan OAuth

Menyetujui asisten hanya satu halaman dan satu scope. Tidak ada yang diberikan sebelum Anda menekan tombol di sana.

Tools

22 tools: aksi burst, baca halaman, tab, media, watch dan wait. 26 primitive browser di bawahnya tidak berubah.

Manusia di loop

Mode foreground butuh izin setiap kali. Password, kode sekali pakai, dan kolom pembayaran ditolak.

Apa yang meninggalkan mesin Anda

Dinyatakan polos, karena asisten dengan akses browser hanya layak dipercaya bila Anda tahu jawabnya. Selengkapnya di kebijakan privasi.

Konten halaman
Konten dari halaman yang Anda setujui hanya pergi ke endpoint model milik Anda. Ia transit melalui relay perintah, dan perintah beserta hasilnya disimpan sebagai riwayat antrean di database project. Ia tidak pernah dibagikan ke pihak ketiga mana pun.
Kunci API
Tersimpan di browser ini. Tidak pernah diunggah, tidak pernah ditampilkan kembali ke halaman ini, tidak pernah dicatat.
Perintah
Antrean dan hasil transit melalui bridge project, agar asisten bisa bertindak di device Anda.
Screenshot
Ditolak di halaman yang menampilkan password, kode sekali pakai, atau kolom pembayaran, dan ditolak di tab private dan incognito.

Pertanyaan yang sering masuk

Jawaban pendek sebelum Anda bertanya ke dukungan.

Berapa biayanya
Masa akses undangan gratis terbatas. Setelahnya bayar per hasil, bukan per bulan: Anda hanya membayar pekerjaan yang selesai.
Model apa
Model apa pun yang punya endpoint API: cloud milik penyedia Anda atau lokal seperti Ollama. Kuncinya milik Anda dan di tangan Anda.
Data saya
Konten halaman hanya pergi ke endpoint model Anda; perintah dan hasilnya transit sebagai riwayat antrean dan tidak pernah dibagikan ke pihak ketiga.
Tanpa internet
Model lokal di mesin ini bekerja tanpa internet. Relay perintah butuh koneksi, karena asisten Anda ada di cloud.
Berhenti
Tombol Keluar melupakan sesi di browser ini. Cabut pairing untuk menghentikan device. Penghapusan riwayat lewat kontak di kebijakan privasi.
