Pasang MCP

Driver lokal Opera Agent berjalan di mesin Anda sendiri — stdio, tanpa login, tanpa biaya per panggilan. Server hosted sudah tidak disediakan lagi; yang dibutuhkan adalah browser yang masuk akun dan ekstensi terpasang.

1. Pasang paketnya

npm install -g opera-agent-mcp

Satu perintah. Paket ini memakai browser yang sudah Anda gunakan; tidak ada proses tambahan yang perlu dijaga.

2. Periksa yang terhubung

opera-agent-mcp doctor

Cetakan menyatakan nama device, paket plan, dan sisa quota hari ini. Kalau tidak ada yang terhubung, paket akan mencetak langkah perbaikan yang paling mungkin.

3. Daftarkan ke harness yang Anda pakai

OpenCode — opencode.json atau ~/.config/opencode/opencode.json

{
  "mcp": {
    "opera-agent": {
      "type": "local",
      "command": "opera-agent-mcp",
      "args": ["local"]
    }
  }
}

Kilo Code — MCP settings (JSON)

{
  "mcpServers": {
    "opera-agent": {
      "command": "opera-agent-mcp",
      "args": ["local"]
    }
  }
}

Claude Desktop — konfigurasi MCP lokal

command: npx
args: ["-y", "opera-agent-mcp", "local"]

Server lokal itu menambah 55 tool di atas 36 primitive browser — daftar lengkap dibawa bersama paket. Tidak ada login, tidak ada quota yang harus dimengerti di website: quota dibaca di lingkungan bridge dan ditampilkan oleh doctor.

4. Satu kali per peramban

Peramban baru harus memasang ekstensi Opera Agent dulu (lihat Unduh) dan menempelkan kode pairing dari halaman pairing di Akun. Setelah itu, driver lokal otomatis mengambil alih — tidak perlu langkah lain setiap sesi.

Batas yang dijaga

  • Password, kode sekali pakai, PIN, kartu, dan CVV selalu ditolak. Pekerjaan yang berhenti di situ gagal — bukan diam-diam diteruskan.
  • Tab private, tab non-http(s), dan jendela tanpa akses debugger: primitive menolak, dan penolakan disebut namanya.
  • Enam izin hanya dipakai untuk enam alasan: tabs, scripting, storage, alarms, debugger, downloads.

Butuh detail teknis? Panduan pemanggilan di docs/agent-call.md menyebut semua jalur secara persis.
