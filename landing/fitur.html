Fitur

Apa yang bisa Opera Agent, dan untuk siapa.

Companion dengan AI di belakangnya. Anda berbicara, asisten mengemudikan browser Anda lewat Opera Agent, dan hasilnya mendarat sebagai artefak nyata: minta dokumen Word di chat, dokumen itu ada.

37 tool, 29 primitive

Opera Agent mengemudikan asisten Anda di browser manapun: kartu, formulir, navigasi, dan tangkapan layar. Google Maps, YouTube, dan Docs adalah tempat utamanya; GitHub dan Wikipedia mengajarkan fungsi baru. Kami menambah tiap situs baru yang nyata, bukan satu happy path per situs.

Lima izin, dijelaskan satu per satu

Setiap aksi jatuh di bawah sebuah izin. Dari popup ekstensi sampai prompt izin di situs, Anda yang memutuskan apakah itu boleh berjalan. Tab, scripting, storage, alarms, dan debugger masing-masing bisa diberikan atau ditolak.

Model milik Anda

Kunci API dan endpoint model yang Anda ketik tidak pernah dikirimkan ke server ini. Konten halaman hanya pergi ke endpoint model yang Anda konfigurasi di perangkat Anda — tiga bentuk pertahanan yang sama di halaman Privasi.

Pairing device

Satu kode berlaku sepuluh menit dan mengikat perangkat baru ke akun Anda (Dashboard). Device yang ter-pairing tetap ter-pairing meskipun Anda keluar dari sesi; kunci hanya dihapus dari memori browser ini, tidak dari akun.

Baca halaman tanpa eksploitasi

Opera Agent dirancang untuk menggerakkan halaman secara halus, tetapi izinnya tegas: model tidak akan disentuh lewat halaman yang menampilkan password, kode sekali pakai, token, atau kolom pembayaran. Semua itu ditolak otomatis.
