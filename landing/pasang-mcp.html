Satu kali di terminal - server ditambahkan ke daftar MCP (project ini; --global untuk semua proyek):

  1. Ketik /terminal. Klik kolom Add follow-up di OpenCode Desktop, ketik /terminal, tekan Enter - panel terminal terbuka di samping output.
  2. Tempel perintah. Di terminal tempel opencode mcp add opera-agent --url https://nenmkmtvjremqphfqnfw.supabase.co/functions/v1/opera-agent-mcp lalu Enter - muncul ✓ opera-agent added.
  3. Ketik /mcp. Kolom composer, ketik /mcp (atau tekan Ctrl+;), tekan Enter - dialog Search MCPs terbuka.
  4. Klik Sign in. Di baris opera-agent (dot oranye Needs auth) klik Sign in; browser terbuka ke halaman Izin aplikasi; klik Izinkan - kembali ke OpenCode, dot hijau dan toggle menyala.
  5. Pakai. Tool muncul sebagai opera-agent_*.

Atau mengedit manual — daftarkan di mcp.servers (skema V2; server tidak langsung di bawah mcp):

{
  "mcp": {
    "servers": {
      "opera-agent": {
        "type": "remote",
        "url": "https://nenmkmtvjremqphfqnfw.supabase.co/functions/v1/opera-agent-mcp"
      }
    }
  }
}

Remote pakai Streamable HTTP + OAuth (PKCE otomatis) — tidak ada header atau clientId yang perlu diisi. Keluar: opencode mcp logout opera-agent.

npx opera-agent-mcp
Sebelum mulai
  1. Extension terpasang. Opera Agent dimuat di Chromium (Unduh).
  2. Sudah di-pair. Buka Dashboard → Pairing → buat kode → tempel di extension.
  3. Jalankan bridge. npx opera-agent-mcp mendengarkan di loopback; harness lokal bisa memakainya langsung.
  4. Nama device. Nama yang Anda pilih saat pairing akan dipakai di semua konfigurasi local.

Verifikasi

Setelah memasang, salin prompt ini ke AI Anda:

Call browser_status and show me the answer.

Extension belum di-pair — buka Dashboard → Pairing, buat kode, tempel di extension, lalu panggil browser_status lagi.
