Pasang MCP

Satu endpoint. Semua AI harness.

ChatGPT, Claude, Codex, Claude Code, OpenCode, VS Code (Copilot), Kilo Code, Cursor, dan terminal - semuanya memakai satu server MCP dengan 35 tool di atas 31 primitive browser.

Yang Anda butuhkan

  1. Extension terpasang. Opera Agent dimuat di Chromium (Unduh).
  2. Sudah di-pair. Buka Dashboard, buka Pairing, buat kode, tempel.
  3. Nama device. Nama yang Anda pilih saat pairing - semua konfigurasi di bawah memakainya.

ChatGPT (web)

  1. Buka Connectors. Pengaturan → Connectors → Advanced → aktifkan Developer mode.
  2. Buat connector. Klik Create → buat koneksi baru, isi nama Opera Agent, URL = endpoint di atas.
  3. Masuk. Klik Authorize / Sign in dan ikuti alur OAuth Opera Agent.
  4. Izinkan semua tool. Di daftar tool connector, pilih Allow all tools (bukan satu-satu). Refresh, atau buka chat baru.

ChatGPT akan memuat tool setelah daftar di-refresh - itu perilaku ChatGPT, bukan error koneksi.

Claude web

  1. Buka Connectors. Di sidebar, klik Customize → Connectors → + → Add custom connector.
  2. Isi nama dan URL. Nama: Opera Agent. URL: endpoint di atas.
  3. Masuk. Klik Add → Authorize → pilih akun Opera Agent Anda.
  4. Izinkan semua tool. Nyalakan seluruh tool connector, lalu buka chat baru.

Codex CLI

Tambahkan ke ~/.codex/config.toml, ganti opera dengan nama device Anda:

[mcp_servers.opera-agent]
url = "https://nenmkmtvjremqphfqnfw.supabase.co/functions/v1/opera-agent-mcp"
headers = { "X-Opera-Device" = "opera", "X-Opera-Provider" = "codex", "x-region" = "ap-southeast-1" }
startup_timeout_sec = 30

Codex akan menandatangani OAuth-nya sendiri. Verifikasi dengan menanyakan status, atau ketik /mcp di Codex dan lihat opera-agent di daftar.

Claude Code

Di terminal, ganti opera dengan nama device Anda:

claude mcp add --transport http opera-agent https://nenmkmtvjremqphfqnfw.supabase.co/functions/v1/opera-agent-mcp --header "X-Opera-Device: opera" --header "X-Opera-Provider: claude" --header "x-region: ap-southeast-1"

Verifikasi: claude mcp list harus menampilkan opera-agent.

Mode lokal (npm), untuk mesin yang sama:

claude mcp add opera-agent -- npx -y opera-agent-mcp local

Terminal (npm)

Satu perintah, satu mesin. Untuk harness yang berjalan di mesin ini:

npm install -g opera-agent-mcp

Empat mode:

opera-agent-mcp local    stdio, drives the open browser on this machine
opera-agent-mcp cloud    stdio, drives it through the hosted server
opera-agent-mcp auth     OAuth sign-in; token stored beside this install
opera-agent-mcp doctor   prints what is connected, the plan, and what the plan allows

Verifikasi koneksi: opera-agent-mcp doctor.

Prompt untuk AI Anda

Tempel di agen Anda - ia akan memasang sendiri:

Set up the Opera Agent MCP server for me. The server is a remote MCP server (Streamable HTTP) at https://nenmkmtvjremqphfqnfw.supabase.co/functions/v1/opera-agent-mcp.

Steps:
1. Ask me for my Opera Agent device name (the name I chose when pairing the extension).
2. Add an MCP server named opera-agent with headers: X-Opera-Device: <that name>, X-Opera-Provider: <your harness name>, x-region: ap-southeast-1.
3. Complete the OAuth sign-in if prompted, and allow all of the server's tools.
4. Verify it works by calling browser_status and paste the answer.

The server controls my own logged-in browser, so treat it as part of my machine: do not use it to bypass logins, passwords, OTPs, or payment steps.

Perintah verifikasi singkat:

Call browser_status and show me the answer, then list the tabs that are open.

Verifikasi

Setelah pasang, tanyakan ke AI: Panggil browser_status dan tampilkan jawabannya. Jawaban yang benar terlihat seperti: ok: true, ekstensi dalam keadaan daring, versi selaras, dan device sesuai nama yang Anda pilih.

Jika paired false atau tidak terdeteksi: extension belum di-pair - buka Dashboard → Pairing dan pair ulang.
