Hanya pergi ke endpoint model milik Anda. Konten dari halaman yang Anda setujui untuk dibaca asisten hanya dikirim ke endpoint model yang Anda konfigurasi sendiri. Kami tidak memilihkan model untuk Anda dan tidak menerima konten itu untuk dibaca manusia.

Relay perintah

Agar asisten bisa bertindak di device Anda, perintah browser beserta hasilnya transit melalui relay project dan disimpan sebagai riwayat antrean di database project. Tidak ada data yang dihapus otomatis; riwayat ada selama akun ada.

Tidak pernah dibagikan ke pihak ketiga

Konten halaman, hasil perintah, dan kunci API Anda tidak pernah dibagikan, dijual, atau diberikan ke pihak ketiga mana pun untuk tujuan apa pun.

Kunci Anda

Kunci API model dan token device tersimpan di browser Anda masing-masing dan tidak pernah ditampilkan kembali ke halaman web mana pun, termasuk halaman situs ini.

Yang selalu ditolak

Screenshot dan pembacaan halaman ditolak di halaman yang menampilkan password, kode sekali pakai, atau kolom pembayaran, serta di tab private dan incognito.

Kontak

Pertanyaan tentang data Anda: semua kendali mandiri ada di halaman Akun — lihat device yang ter-pairing, cabut yang tidak dikenal, keluar dari sesi. Temuan keamanan jangan dibuka sebagai isu publik; laporkan privat lewat tab Security di repositori.
