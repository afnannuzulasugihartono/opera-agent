  1. Unduh arsip. Klik Unduh .zip di atas; berkas mendarat di Downloads.
  2. Ekstrak arsip. Extract all di toolbar Explorer; pilih folder tetap, misalnya C:\OperaAgent\.
  3. Buka halaman ekstensi. chrome://extensions, nyalakan Developer mode.
  4. Muat folder. Load unpacked — pilih folder hasil ekstrak.
  5. Pasangkan device. Dasbor, tempel kode pairing.
  6. Verifikasi berkas. Kedua sidik jari harus sama.

Verifikasi berkas

Sidik jari berubah setiap rilis. Bandingkan dengan server:

server
lokal 
Get-FileHash .\opera-agent-*.zip -Algorithm SHA256

Kedua angka harus sama.
