Lima langkah memasang dari arsip
  1. Ekstrak arsip. Ke folder tetap, misalnya C:\OperaAgent\.
  2. Buka halaman extension. chrome://extensions.
  3. Aktifkan mode pengembang. Toggle pojok atas.
  4. Muat folder. Load unpacked — pilih folder berisi manifest.json.
  5. Pasangkan device. Dashboard, tempel kode pairing.

Verifikasi berkas

Sidik jari berubah setiap rilis. Bandingkan dengan server:

server
lokal 
Get-FileHash .\opera-agent-*.zip -Algorithm SHA256

Kedua angka harus sama.
