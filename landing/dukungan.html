Dukungan

Tidak ada di daftar? Ctrl K mencari semua halaman.

01Device tidak muncul di Dashboard

Buka Dashboard dan lihat status tiap device. Jika offline, pasangkan ulang lewat kode baru di sana. Jangan biarkan device tak dikenal tetap ter-pairing; cabut yang tidak Anda kenal.

02Ekstensi tidak ter-pasang

Ikuti Unduh. Jika tombol instalasi otomatis diblokir, pakai arsip mentah dan aktifkan mode pengembang, lalu centang browser Anda dan tekan Pasang. Periksa chrome://extensions dan chrome://policy.

03Menghubungkan AI harness (OpenCode, Kilo, ChatGPT, Claude)

Server MCP, header device, dan config OpenCode, Kilo, serta Claude ada di halaman Docs.

04Sesi Anda keluar sendiri

Token akses kedaluwarsa sekitar satu jam. Biasanya diperbarui otomatis lewat refresh token yang tersimpan; jika refresh ikut gagal, Anda dipulangkan ke Masuk. Itu disengaja, bukan kehilangan akun. Riwayat perintah tetap ada.

05Privasi dan data

Pertanyaan tentang kendali data: semuanya mandiri di halaman Akun dan Privasi. Temuan keamanan jangan dibuka sebagai isu publik; laporkan privat lewat tab Security di repositori.
