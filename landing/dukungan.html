Dukungan

Di mana Anda bisa minta tolong, dan di mana Anda bisa lapor.

Ini produk yang dioperasikan sendiri, jadi dukungan paling efektif adalah langkah konkret di bawah.

Device tidak muncul di Dashboard

Buka Dashboard dan lihat status tiap device. Jika offline, pasangkan ulang lewat kode baru di sana. Jangan biarkan device tak dikenal tetap ter-pairing; cabut yang tidak Anda kenal.

Ekstensi tidak ter-pasang

Ikuti Unduh. Jika tombol instalasi otomatis diblokir, pakai arsip mentah dan aktifkan mode pengembang, lalu centang browser Anda dan tekan Pasang. Periksa chrome://extensions dan chrome://policy.

Menghubungkan AI harness (OpenCode, Kilo, ChatGPT, Claude)

Server MCP:

https://nenmkmtvjremqphfqnfw.supabase.co/functions/v1/opera-agent-mcp

Masuk dengan akun Anda (OAuth). Nama device terlihat di Dashboard beserta browser dan provider tiap perintah (misalnya opera / Brave / opencode).

OpenCode

Tambah ke opencode.json, ganti opera dengan nama device Anda:

{
  "mcp": {
    "opera-agent": {
      "type": "remote",
      "url": "https://nenmkmtvjremqphfqnfw.supabase.co/functions/v1/opera-agent-mcp",
      "oauth": { "clientId": "bbc5eb76-f385-435b-8b13-8e339b45e633" },
      "headers": {
        "X-Opera-Device": "opera",
        "X-Opera-Provider": "opencode"
      }
    }
  }
}

Kilo Code

Tambah ke MCP settings (JSON), ganti opera dengan nama device Anda:

{
  "mcpServers": {
    "opera-agent": {
      "url": "https://nenmkmtvjremqphfqnfw.supabase.co/functions/v1/opera-agent-mcp",
      "headers": {
        "X-Opera-Device": "opera",
        "X-Opera-Provider": "kilo"
      }
    }
  }
}

Claude Code

Di terminal, ganti opera dengan nama device Anda:

claude mcp add --transport http opera-agent https://nenmkmtvjremqphfqnfw.supabase.co/functions/v1/opera-agent-mcp --header "X-Opera-Device: opera" --header "X-Opera-Provider: claude"

ChatGPT dan konektor lain tanpa header kustom

Cukup URL server di atas plus OAuth. Server memakai device pertama milik akun Anda dan menebak provider secara otomatis. Untuk memilih device lain, pasangkan ulang atau hubungi pemilik akun.

Setelah terpasang: buka pengaturan konektor, pilih Allow all tools, lalu refresh atau buka chat baru. Daftar tools baru muncul sesudah itu — itu perilaku ChatGPT, bukan error koneksi.

Sesi Anda keluar sendiri

Token akses kedaluwarsa sekitar satu jam. Biasanya diperbarui otomatis lewat refresh token yang tersimpan; jika refresh ikut gagal, Anda dipulangkan ke Masuk. Itu disengaja, bukan kehilangan akun. Riwayat perintah tetap ada.

Privasi dan data

Pertanyaan tentang kendali data: semuanya mandiri di halaman Akun dan Privasi. Temuan keamanan jangan dibuka sebagai isu publik; laporkan privat lewat tab Security di repositori.
